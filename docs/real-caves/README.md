# Real-cave layouts for *Flesh of the Ancients*

The user asked that every cave in the game be modeled after a real cave, using maps and surveys where they can be found. This folder is the research record. Playable layouts live in [`data/real-caves/`](../../data/real-caves/).

The game already stores a cave as a **centerline plus passage widths** (`format: cavern-centerline-v1` in `js/cave-data.js`): stations have `x, y, z` in metres (x east, y north, z up) and LRUD widths, with `legs` between them. That is the same idea as a Survex / Compass survey. The existing Carlsbad option in `data/carlsbad.json` was built that way from public NPS maps (`tools/make_carlsbad.py`). The planned next rebuild still uses a layout, but assembles the mesh from modular pieces (`tunnel`, `junction`, `hall`, `squeeze`, `pit`). Each JSON here adds:

- `tags` on stations: `entrance`, `hall`, `squeeze`, `pit`, `stream`, `formation zone`, `art wall`
- a derived `module` field naming the piece type for that rebuild

**Do not treat these JSON files as surveys.** They are playable approximations. Where a copyrighted map was the only detailed plan, it is flagged **inspiration only**: we may loosely follow published room order and measurements, but we must not trace the drawing.

No raw open Survex / Therion / Compass / Walls files were found for the famous caves on this list. Public survey repositories that *do* have other systems (and could be converted later) include [Cave Registry Data Archive](https://cave-registry.org.uk/), [openspeleo.org](https://www.openspeleo.org/openspeleo/?lang=en), and [iccaving/migovec-survey-data](https://github.com/iccaving/migovec-survey-data) (CC BY-NC-SA, so not freely usable in a commercial game without a separate licence).

## Licensing rules (read this first)

- **US government works** (NPS, USGS, USFS maps and official brochures) are public domain in the United States. These are the best sources we have. Approximate layouts derived from them are fine.
- **Works old enough to be public domain** (for example the 1908 Max Kämper map of Mammoth Cave, the 1856 Postojna section) are fine to use as references.
- **Creative Commons maps** can be used if the licence is compatible. Share-alike (CC BY-SA) means a *traced* derivative should stay under the same licence. The Altamira plan is the main example. We did not trace it for a JSON file in this pass.
- **Copyrighted modern maps** (French Ministry of Culture atlases for Lascaux and Chauvet, the Richard Schlecht Mammoth Cave tour map, the 2003 Timpanogos Cave Atlas, commercial Son Doong / Postojna / Waitomo / Eisriesenwelt maps, journal site plans) are **inspiration only**. Do not digitise or trace them. We may use publicly stated room names, tour order, and published measurements.
- A Wikimedia file being CC-licensed is not enough if it is a redraw of a still-copyrighted atlas. `File:Lascaux plan-ru.JPG` is that case (redrawn after Leroi-Gourhan 1984) and was not traced.
- Photographs of NPS signs may themselves be CC-licensed even when the sign is a US government work. The Lehman visitor-center photo is CC BY-SA 4.0 (Famartin); the sign is PD. We used the published NPS plan structure and dimensions, not a tracing of the photo.

## How to load a layout

The six JSON files use the same schema as `data/carlsbad.json`, so `parseJSONSurvey()` in `js/cave-data.js` should accept them. A loader has not been wired in this pass (another worker is editing the game). After a file is loaded, `station.module` and `station.tags` can drive the modular piece rebuild.

| Seed | JSON | Preview | Scale | Stations |
|---|---|---|---|---|
| `lascaux` | [data/real-caves/lascaux.json](../../data/real-caves/lascaux.json) | [lascaux.png](lascaux.png) | 1.0× | 19 |
| `carlsbad` | [data/real-caves/carlsbad.json](../../data/real-caves/carlsbad.json) | [carlsbad.png](carlsbad.png) | 1.0× | 51 |
| `mammoth` | [data/real-caves/mammoth.json](../../data/real-caves/mammoth.json) | [mammoth.png](mammoth.png) | 0.35× xy, 0.5× z | 21 |
| `wind-cave` | [data/real-caves/wind-cave.json](../../data/real-caves/wind-cave.json) | [wind-cave.png](wind-cave.png) | 1.0× | 34 |
| `lehman` | [data/real-caves/lehman.json](../../data/real-caves/lehman.json) | [lehman.png](lehman.png) | 1.0× | 17 |
| `timpanogos` | [data/real-caves/timpanogos.json](../../data/real-caves/timpanogos.json) | [timpanogos.png](timpanogos.png) | 1.0× | 14 |

Regenerate JSON and previews with:

```bash
python3 docs/real-caves/build_layouts.py
```

`carlsbad.json` here is a tagged copy of the existing `data/carlsbad.json`. The original file was not edited.

## What is ready to load

These six files are ready for `parseJSONSurvey()`:

1. **Lascaux** — small painted cave, 1:1, art-wall tags and a shaft. Best story fit.
2. **Carlsbad** — already-proven tour model, now tagged. Largest and most detailed.
3. **Mammoth Cave (Historic Tour)** — scaled trunk passage, squeeze, pit, and river branch.
4. **Wind Cave (tour routes)** — maze-like connected tours with boxwork / formation tags and real relative elevations.
5. **Lehman Caves** — compact decorated rooms, good Intermountain pick next to Utah.
6. **Timpanogos Cave System** — the local Utah cave, a short linear three-cave tour.

Suggested use in the game: Lascaux-shaped painted caves for story / art walls; Carlsbad- or Lehman-shaped halls for formation-rich deep caves; Wind Cave for maze levels; Mammoth for long trunk-and-river trips; Timpanogos for a cliff-side local cave.

## Caveats for the next worker

- Coordinates are already in game metres. Only Mammoth is scaled down (see `scale` / `verticalScale` in the JSON).
- Widths of squeezes (Fat Man's Misery, Lascaux Passageway, Roe's Misery, Timpanogos Lower Passage) were kept tight on purpose.
- `carlsbad.json` in this folder is a copy. Keep `data/carlsbad.json` as the live game file until a loader points here.
- Wind Cave's short "boxwork spurs" are invented connectors, called out in `source.note`.
- Altamira is the strongest cave *not* yet turned into JSON, because of the CC BY-SA Museo plan. If it is added later, attribute the museum and keep share-alike in mind if the plan is traced.
- Do not ship traced geometry from the Kowallis Timpanogos atlas, the Schlecht Mammoth map, or the French Lascaux / Chauvet atlases.
